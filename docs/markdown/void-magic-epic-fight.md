# Пустотный меч: обычный бой и Epic Fight

Эффекты `jdh:void_sword` разделены между двумя модами:

- `echo-void-magic-0.1.3.jar` содержит частицу, общую геометрию клинка и обычный ванильный след;
- `echo-void-magic-epicfight-adapter-0.1.0.jar` подключает боевые события и анимации Epic Fight.

## Что происходит при атаке

В обычном бою базовый мод читает ванильный взмах и оставляет за клинком зелёный след с lifetime 5 тиков. Адаптер отслеживает фактически нанесённый урон и создаёт на цели короткий пустотный разрез, поэтому промах не показывает ложное попадание.

В режиме Epic Fight ванильные поля `swinging/swingTime` не используются. Адаптер читает `PlayerPatch`, состояние `attacking`, текущую `AttackAnimation` и её elapsed/total time. Из этого времени строится положение дуги клинка, а между соседними положениями кончика добавляются частицы, чтобы быстрый кадр не оставлял разрывов.

## Зависимости

- Minecraft Forge 1.20.1;
- Echo Magic 0.4.4+;
- Echo Void Magic 0.1.3+;
- Epic Fight 20.14.17–20.14.x.

Адаптер не встраивает внутрь себя классы зависимостей. Серверный эффект попадания отделён от клиентского рендера частиц, поэтому мод безопасно загружается на dedicated server.

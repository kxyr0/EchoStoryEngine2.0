# Эхо магия: краткая памятка

## Первый запуск

Выдай нужные школы командами администратора:

```text
/echo_fire_magic setup @s
/echo_water_magic setup @s
/echo_air_magic setup @s
/echo_blood_magic setup @s
/echo_void_magic setup @s
/echo_spark_magic setup @s
```

`N` выбирает школу, `V` рисует технику. Пока держишь `N` или `V`, зажимай ЛКМ только на время штриха. Отпусти ЛКМ, чтобы закончить штрих, и клавишу режима — чтобы подтвердить весь рисунок. Обе клавиши меняются в `Настройки → Управление → Эхо магия`.

Школы через `N`: Огонь `↑`, Вода `~`, Воздух `○`, Кровь `•` с удержанием, Пустота `↔` — линия туда и обратно. Земля `⊥` распознаётся, но готовых заклинаний Земли пока нет.

## Составные рисунки

- Линия или дуга, затем отдельная удерживаемая точка — атака с задержкой 2 секунды.
- Круг, затем точка — печать в трёх блоках впереди; срабатывает, когда враг войдёт внутрь.
- Основная форма, затем `V`-образная развилка у её конца — атака делится на три направления.
- `J`-образный крюк, затем точка — связь с врагом перед игроком; в школе Пустоты игрок и цель сразу меняются местами.

## Hot reload `.es`

Редактируй живые файлы Prism здесь:

```text
C:\Users\kxyr0\AppData\Roaming\PrismLauncher\instances\Форма Мысли\minecraft\story\content-pack\jdh\data\jdh\echo_magic\spells\
```

После сохранения, создания, переименования или удаления `.es` каталог автоматически обновится примерно за `0,5–0,75` секунды. `/reload`, перезапуск мира и пересборка JAR не нужны. Администратор увидит количество загруженных заклинаний.

Если в DSL есть ошибка или повторяется Spell ID, hot reload отклоняется, а последняя рабочая версия продолжает действовать. Исправь файл и снова сохрани его. Автоперезагрузка следит только за `.es`; изменение Java, текстур, particle JSON или переводов требует обычной сборки и перезапуска.

# Echo Damage Numbers

`echo-damage-numbers` — отдельный Forge 1.20.1 мод, который показывает фактический урон над врагом в мировом пространстве.

## Когда появляется число

Popup получает только игрок, который причинил урон. Цель должна быть:

- hostile-сущностью, реализующей vanilla `Enemy`;
- мобом, который сейчас атакует этого игрока;
- другим игроком, не являющимся союзником или членом той же команды.

Мирные NPC, союзники, члены команды, собственные приручённые существа и случайно задетые животные не создают popup. Для числа используется `LivingDamageEvent`, поэтому показывается финальный damage после брони, эффектов и absorption. Урон от меча, стрелы и Echo Magic работает через один общий путь.

## Анимация

Число появляется над верхней границей сущности, быстро увеличивается с небольшим overshoot, поднимается с боковым движением по синусоиде, затем уменьшается и одновременно исчезает. Полная длительность — около 2 секунд (40 ticks); основная часть этого времени остаётся полностью читаемой. Одновременно хранится не больше 128 popup.

Цвет зависит от силы удара: обычный урон жёлтый, средний оранжевый, большой красный.

# Codex Workflow

1. Read `AGENTS.md`.
2. Read `docs/architecture/PROJECT_MAP.md`.
3. Read `PROGRESS.md`.
4. Read docs for the area being changed.
5. Run `git status --short --branch`.
6. Write a short plan and expected file list.
7. Apply the scope firewall from `docs/architecture/SCOPE.md`.
8. Make a coherent change.
9. Run the smallest meaningful checks, then the required final checks.
10. Update docs when structure or behavior changes.
11. Review the diff against `docs/development/REVIEW_CHECKLIST.md`.
12. Report exact commands and results.

Do not stop after writing a plan when there is no blocker.

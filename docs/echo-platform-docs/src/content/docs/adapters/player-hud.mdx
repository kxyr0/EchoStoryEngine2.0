# HUD adapters

HUD adapters связывают владельцев gameplay state с renderer-ом через public API.

```text
Echo Player Vitals public API
-> HUD Vitals Adapter
-> echo_player_hud:stamina

Echo Content Player public API
-> HUD Content Player Adapter
-> echo_player_hud:spark
```

Правила:

- adapter не сохраняет fatigue или Spark;
- adapter не импортирует core/runtime implementation владельца;
- HUD получает только `HudMetricSnapshot`;
- если provider отсутствует, соответствующая bar не рисуется, а остальные продолжают работать.

Spark не дублируется в Vitals. Его owning source остаётся `echo-content-player`.

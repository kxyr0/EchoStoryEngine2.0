# Постановка NPC и сон

N4 добавляет предметные команды сцены: `Npc.SpawnAt`, `Npc.SleepAt`, `Npc.WakeUp` и predicates `Npc.IsMaterialized`, `Npc.IsSleeping`, `Npc.IsSleepingAt`.

`SpawnAt` работает с durable `ActorId` и не создает duplicate entity. `SleepAt` требует точный `BlockPosition` и `expectedBlock`; runtime не ищет ближайшую кровать. `WakeUp` освобождает attachment и occupied state через тот же rest provider.

## Flow

```text
Player setup
-> Npc.SpawnAt
-> materialization
-> scene-ready
-> Npc.SleepAt
-> bed provider
-> sleeping attachment
-> Dialogue.Load
```

Story adapter exposes `echo_npc:spawn_at`, `echo_npc:sleep_at` and `echo_npc:wake_up` action ids for the same runtime service.

# Катсцены

Echo Cutscene управляет detached camera. Echo Player Actor управляет body.

Adapter берёт lease на `PLAYING/ACCEPTED` и отпускает его на terminal lifecycle. Текущий public Cutscene API не отдаёт Dialogue owner lineage, поэтому adapter не импортирует cutscene core ради этой информации.

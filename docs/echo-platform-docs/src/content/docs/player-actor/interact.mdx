# Interact

`Player.Interact(x, y, z, face, hand)` проверяет reach и line of sight, затем вызывает серверный `useItemOn` pipeline.

Это не `RightClick` и не зависит от keybindings. Receipt фиксирует command/target, но arbitrary mod block без transaction boundary не получает обещание exactly-once.

# Rotate

`Player.Rotate(yaw, pitch)` задаёт абсолютный yaw/pitch. С `duration` команда становится blocking и прогрессирует по server tick с `LINEAR`, `SMOOTH` или `CUBIC`.

Команда относится к body игрока, не к detached camera.

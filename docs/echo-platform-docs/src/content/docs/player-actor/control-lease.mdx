# Control Lease

Для одного `PlayerActorId` активен максимум один exclusive lease. Во время катсцены adapter берёт `CINEMATIC_CONTROL`, блокируя пользовательское управление body, но разрешая команды authorised owner.

Конфликтующий owner получает `PLAYER_ACTOR_CONTROL_ALREADY_LEASED` или `PLAYER_ACTOR_CONTROL_OWNER_MISMATCH`.

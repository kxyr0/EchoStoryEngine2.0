# Recovery

Core содержит command ledger и lease registry. Runtime W1 хранит active movement/rotation in-memory и предоставляет `/echo_player_actor control release <player>` для аварийного возврата human control.

SavedData recovery должен сохранять lease, active command и receipts до dispatch.

# Move

`Player.Move(destination)` является blocking командой. Runtime отклоняет движение, если actor сидит, и не выполняет cross-dimension movement.

Movement adapter делает Navigation preflight, а `PlayerActorMotor` двигает настоящее body через collision-aware server movement.

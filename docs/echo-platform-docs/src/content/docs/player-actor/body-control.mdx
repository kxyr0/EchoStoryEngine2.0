# Управление телом

Поток команды: EchoScript → script adapter → `PlayerActorService` → lease validation → body operation → result → script resume.

Низкоуровневые команды вроде `PressButton`, `ReleaseButton`, `SimulateInput` и `RightClick` отсутствуют. Сценарий описывает действие героя, а не клавишу пользователя.

# Игрок как актёр

Echo Player Actor управляет настоящим `ServerPlayer`. Он не создаёт NPC-клон, не скрывает body, не переводит игрока в spectator и не телепортирует его в отдельную комнату.

Тело сохраняет внешний вид, Wardrobe outfit, предметы, здоровье, инвентарь, позу и Dialogue identity. Камера остаётся ответственностью Echo Cutscene.

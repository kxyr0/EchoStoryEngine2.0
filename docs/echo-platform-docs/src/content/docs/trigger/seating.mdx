# Seating triggers

Echo Seating добавляет authored зоны посадки без привязки к мебельному моду. Runtime не сканирует блоки каждый tick. Источник истины: server-side riding transition, затем resolved `SeatAnchor`, проверка `SeatZoneCatalog` и `SeatSlotMatcher`.

Trigger selectors:

```csharp
Subscribe(Player.SeatedIn(BreakfastTable));
Subscribe(Player.SeatedAt(BreakfastTable, MothersSeat));
Subscribe(Player.StoodUpIn(BreakfastTable));
Subscribe(Player.StoodUpFrom(BreakfastTable, MothersSeat));
Subscribe(Player.ChangedSeatIn(BreakfastTable));
```

`SeatedIn` срабатывает для любого publishable anchor внутри зоны. `SeatedAt` требует exact authored `SeatSlotId`.

Subscription target может быть story или dialogue:

```csharp
Subscribe(Player.SeatedAt(BreakfastTable, MothersSeat));
StartDialogue("jdh:dialogue/wrong_mothers_seat");

Subscribe(Player.SeatedAt(BreakfastTable, PlayerSeat));
StartStory("jdh:chapter_1/breakfast_main_story");
```

`StartDialogue` запускает Echo Dialogue напрямую на игрока seating event. `StartStory` оставляет полный StoryResource path для сцен, флагов, NPC, cutscene и дальнейших действий.

Контекст Story получает `player`, `seat.zone`, optional `seat.slot`, `seat.event`, `seat.anchor`, `seat.vehicle`, `seat.vehicleType`, `trigger.subscription` и `trigger.execution`.

# Руки и экипировка

`Holding`, `HoldingMainHand`, `HoldingOffHand` являются predicates. `MainHandChanged`, `OffHandChanged`,
`EquipmentEquipped`, `EquipmentUnequipped` являются events и не создаются при recovery.

Armor slots: `HEAD`, `CHEST`, `LEGS`, `FEET`.

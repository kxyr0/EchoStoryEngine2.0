# Эффекты

`HasEffect`, `EffectAmplifierAtLeast` и `EffectDurationAtLeast` являются predicates. `EffectAdded`, `EffectRemoved` и
`EffectAmplifierChanged` являются events.

Amplifier использует vanilla значение: `0` это уровень I, `1` это уровень II.

# Предметы и инвентарь

`HasItem` читает hotbar, main inventory и offhand. Armor, Ender Chest, открытый container и cursor stack не входят.

`"minecraft:diamond"` означает Item ID. `"#minecraft:planks"` означает Item Tag. Echo Item Pack виден через обычный
Forge registry ID, без прямой зависимости.

<InventoryTriggerLab client:load />

```csharp
Trigger.Wait(HasItem("minecraft:diamond", count: 3));
Trigger.Wait(ItemAdded("#minecraft:wool", count: 2));
```

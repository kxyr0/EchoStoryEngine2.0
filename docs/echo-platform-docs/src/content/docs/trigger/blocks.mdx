# Взаимодействие с блоками

Block events accept block ID or tag and optional `area`. Area checks the block position and dimension. Player position
does not have to be inside the area.

```csharp
Trigger.Wait(BlockInteracted("#minecraft:doors", area: Exit, hand: MAIN_HAND));
```

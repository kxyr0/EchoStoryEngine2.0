# Измерения и режим игры

`InDimension(id)` и `GameModeIs(mode)` являются predicates. `DimensionChanged`, `DimensionEntered`, `DimensionLeft` и
`GameModeChanged` являются events.

Game modes: `SURVIVAL`, `CREATIVE`, `ADVENTURE`, `SPECTATOR`.

# Время и погода

`TimeBetween(startTick, endTick)` использует vanilla day time `0..23999` и поддерживает переход через полночь.
`TimeReached(dayTime)` реагирует на обычный tick, `/time set`, `/time add`, sleep skip и большие скачки.

Weather values: `CLEAR`, `RAIN`, `THUNDER`.

# Predicate против Event

Predicate проверяет текущее состояние: `HasItem`, `HealthAtMost`, `HasEffect`, `InDimension`.

Event фиксирует переход после подписки: `ItemAdded`, `PlayerDied`, `BlockInteracted`, `TimeReached`.

После restart или recovery predicate можно переоценить по текущему snapshot. Event нельзя синтетически создать из уже
существующего состояния.

<InventoryTriggerLab client:load />

```csharp
Trigger.Wait(HasItem("minecraft:diamond"));
Trigger.Wait(ItemAdded("minecraft:diamond"));
```

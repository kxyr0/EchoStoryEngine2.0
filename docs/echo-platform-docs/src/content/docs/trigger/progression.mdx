# Прогресс и достижения

`AdvancementCompleted(id)` проверяет текущее состояние. `AdvancementGranted(id)` срабатывает только на grant после
подписки. Отсутствующий advancement ID должен давать diagnostic, а не тихое `false`.

`ExperienceLevelReached(level)` является edge event: previous level меньше цели, current level больше или равен цели.

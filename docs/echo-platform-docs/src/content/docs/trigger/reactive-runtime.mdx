# Reactive runtime

Forge bridge снимает позицию игрока в конце server tick и отправляет в core предыдущую и текущую позицию вместе с
previous/current dimension. Первый snapshot считается baseline и не создает synthetic enter.

Core runtime хранит membership по стабильному trigger instance id:

- inside/outside state;
- общий fire count;
- consumed one-shot callback kinds;
- cooldown expiry tick;
- next stay tick.

Когда transition принят, runtime возвращает `TriggerCallbackInvocation`. Он не исполняет action body сам и не импортирует
Dialogue, Story или Player implementation modules.

Forge публикует invocation как public `TriggerCallbackInvocationEvent` из `trigger-forge-api-1.20.1`. Любой adapter
может слушать этот event и решать, какие action names он поддерживает.

Для будущего echo-debug есть read-only `TriggerAreaCatalogView`: trigger id, area name, dimension, shape kind, min, max
и center. Debug GUI и wands не входят в T3.

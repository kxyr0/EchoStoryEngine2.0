# Обзор анимации

Animation core работает с logical subject, профилями, клипами и каналами. Он не импортирует NPC и не знает UUID сущности. Внешний домен может дать ему owner, но управляет playback только через публичный API.

<AnimationLifecycleLab client:load />

## Основная цепочка

`AnimationProfileId` описывает authoring resource. `AnimationSubjectId` закрепляет состояние за логическим владельцем. `AnimationPlaybackId` появляется на время конкретного проигрывания. Lease защищает канал от двух конфликтующих движений.

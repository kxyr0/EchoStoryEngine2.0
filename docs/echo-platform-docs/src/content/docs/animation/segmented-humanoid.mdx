# Сегментированная модель

Сегменты модели, UV, ладони, лицо и зоны рендера.

Эта страница фиксирует рабочий контракт раздела «Анимация»: какие ID должны оставаться стабильными, где проходит граница ответственности и что проверять при ошибке в контенте или состоянии во время игры.

## Контракт во время игры

- Долговечные ID должны быть логическими и иметь namespace.
- Сервер остаётся единственным источником состояния. Клиенты получают только снимки и изменения.
- Согласование должно быть идемпотентным: повторная проверка не перезапускает уже активное проигрывание.
- Диагностика ограничена по размеру, чтобы один сломанный ресурс не ломал соседних актёров.

## Что смотреть разработчику

- Проверьте ID из `.es` и путь файла в контент-паке.
- После правки выполните `/reload`.
- Смотрите профильную диагностику: `/echo_story diagnostics 20`, `/echo_dialogue diagnostics 20`, `/echo_npc diagnostics 20`, `/echo_animation diagnostics 20`.
- Если страница связана с адаптером, проверьте `/echo_story extensions` и соответствующий мост.

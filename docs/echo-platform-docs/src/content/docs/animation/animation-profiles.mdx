## Что проверяет binder

`AnimationProfile` не является комментарием к Java-коду. Это content resource, который parser переводит в AST, binder связывает с `AnimationProfileId`, а система во время игры использует при `ensure subject`.

Binder проверяет:

- что ID профиля namespaced;
- что rig существует;
- что graph описывает разрешённые фазы;
- что required channels можно занять через lease;
- что initial state не сбрасывает существующий playback без безопасного rebind.

## Контракт во время игры

После успешного bind профиль становится частью generated contract. Он доступен адаптеру только через публичный API, поэтому NPC integration не импортирует internals анимации.

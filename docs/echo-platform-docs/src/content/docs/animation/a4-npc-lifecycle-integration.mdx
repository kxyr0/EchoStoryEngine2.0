## Что делает адаптер

A4 связывает долговечный `ActorId` с `AnimationSubjectId` автоматически. Адаптер читает публичные снимки NPC, выбирает авторский `NpcAnimationBinding`, создаёт subject через публичный Animation API и затем циклом согласования догоняет пропущенные изменения.

UUID сущности при этом не является основным identity. После выгрузки чанка и повторной материализации новая сущность получает того же логического актёра и тот же субъект анимации, если subject принадлежал адаптеру.

## Состояния во время игры

| Состояние NPC | Сущность | Субъект анимации | Проигрывание |
| --- | --- | --- | --- |
| Durable `ACTIVE`, чанк загружен | материализована | должен существовать | продолжается |
| Durable `ACTIVE`, чанк выгружен | временно отсутствует | сохраняется | продолжается на сервере |
| Durable `ACTIVE`, восстановлена | новый UUID | тот же subject | не перезапускает `ENTER` |
| Durable `ABSENT` | отсутствует | retire, если subject принадлежал адаптеру | terminal `SUBJECT_OWNER_REMOVED` |
| `UNBOUND` | может существовать | не создаётся | обычный renderer NPC |

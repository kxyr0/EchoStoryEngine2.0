# Echo Effects

Echo Effects adds declarative player effects defined as `.es` content:

```text
EffectResource
-> EchoScript parser
-> EffectResource binder
-> immutable EffectDefinition
-> EffectRuntime
-> ActiveEffectInstance
-> channel contributions
```

Content path:

```text
<gameDir>/story/content-pack/<namespace>/echo_effects/effects/
```

The EF1 repository is `D:/JDHSeason/mods/echo-effects`. It contains neutral `effects-contracts`, plain Java `effects-core`, `effects-script-adapter-1.20.1`, `effects-forge-api-1.20.1`, `effects-forge-1.20.1`, and a development-only testmod.

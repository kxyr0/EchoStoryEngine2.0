# Face Slot

The `FACE` slot maps to the vanilla `HEAD` equipment slot and becomes the `FACE=` part of `OutfitKey`. The resolved face pixels come from `faceSkin`.

<GlassesPortraitLab client:load />

Optional item models can render accessory geometry, but they do not replace the exact full skin.

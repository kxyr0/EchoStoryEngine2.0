# Echo Wardrobe

Echo Wardrobe resolves the player's wardrobe by exact authored combinations:

```text
Minecraft equipment -> item IDs -> WearableDefinition -> OutfitKey
-> exact OutfitVariantResource -> full 64x64 PNG -> ResolvedOutfit
```

<OutfitResolverLab client:load />

The runtime does not compose skins, blend overlays, use UV masks, or choose closest matches. Missing combinations fall back to the profile base skin and report `WARDROBE_OUTFIT_VARIANT_NOT_FOUND`.

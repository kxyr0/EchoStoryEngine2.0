# Full Skins

Put PNG files under `assets/<namespace>/textures/echo_wardrobe/skins/...` and reference them without `textures/` or `.png`:

```es
Skin("jdh:echo_wardrobe/skins/origin/jdh_full_dressed");
```

<OutfitResolverLab client:load />

`Skin(...)` sets both `worldSkin` and `faceSkin`. Use `WorldSkin(...)` and `FaceSkin(...)` only when they intentionally differ.

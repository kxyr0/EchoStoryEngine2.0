# Dialogue Portrait

Dialogue does not import Wardrobe. Portrait rendering reads Content Player's resolved appearance and uses `faceSkin` plus appearance revision.

<GlassesPortraitLab client:load />

If a wardrobe outfit changes, the portrait follows the same revision boundary as the player renderer.

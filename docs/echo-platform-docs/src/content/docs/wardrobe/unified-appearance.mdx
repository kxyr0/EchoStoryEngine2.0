# Unified Player Appearance

Echo Content Player owns the public appearance registry and resolved appearance boundary. Echo Wardrobe contributes `worldSkin`, `faceSkin`, models, catalog revision, and appearance revision through `wardrobe-content-player-adapter-1.20.1`.

<OutfitResolverLab client:load />

Dialogue, Animation, inventory preview, and render consumers read Content Player. They do not import Wardrobe runtime or core packages.

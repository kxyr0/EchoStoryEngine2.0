# Обзор системы

Echo делит состояние во время игры по владельцам. NPC отвечает за durable actor и materialization. Animation отвечает за subject, playback и lease. Адаптер связывает оба домена через публичный API и не переносит приватные сущности между модулями.

## Точка опоры

Главный инвариант: логические ID переживают физическое состояние. `ActorId` не равен UUID сущности. `AnimationSubjectId` не выводится из текущей сущности. `AnimationPlaybackId` описывает конкретное проигрывание, а не персонажа.

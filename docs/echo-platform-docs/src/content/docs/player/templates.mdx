# Шаблоны профилей

Шаблон проходит реальный EchoScript parser и затем semantic binder. Он не исполняется как runtime code.

```csharp
class DefaultPlayerProfile : PlayerProfileTemplate
{
    public override PlayerProfile Build()
    {
        return PlayerProfile(id: "jdh:player/default", spark: 100, maxSpark: 100);
    }
}
```

Default template применяется только при первом создании профиля. Existing profiles не перезаписываются hot reload-ом.

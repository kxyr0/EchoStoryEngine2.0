# Ошибки профиля

Коды P1:

- `PLAYER_NAME_INVALID`;
- `PLAYER_SKIN_INVALID`;
- `PLAYER_TEMPLATE_PARSE_ERROR`;
- `PLAYER_TEMPLATE_BIND_ERROR`;
- `PLAYER_MUTATION_CONFLICT`;
- `PLAYER_PROFILE_MISSING`.

Broken template не перезаписывает существующие профили. Broken skin не публикуется и не делает игрока невидимым. Mutation conflict не выполняет вторую операцию.

# Профиль игрока

Minecraft `ServerPlayer`, numeric entity id, account name и `EchoPlayerId` не взаимозаменяемы. Durable профиль привязан к UUID аккаунта через `EchoPlayerId`; respawn, dimension change, reconnect и restart не создают новый профиль.

## Snapshot

`PlayerProfileSnapshot` содержит identity, Spark, base appearance, template id/fingerprint, lifecycle metadata, profile revision и repository revision. Профиль не хранит quest state, dialogue state, inventory, wardrobe layers, RPG stats или UI settings.

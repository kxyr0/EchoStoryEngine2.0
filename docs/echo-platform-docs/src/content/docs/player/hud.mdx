# HUD игрока

Echo Player HUD владеет только отображением. Он не меняет здоровье, Искру, fatigue, hunger или gameplay effects.

Поток рендера:

```text
HudMetricProvider
-> HudMetricSnapshot
-> HudLayoutSnapshot
-> framebuffer transform
-> bar fill
```

Стандартные метрики:

- `echo_player_hud:health`;
- `echo_player_hud:spark`;
- `echo_player_hud:stamina`.

Layout считается в framebuffer coordinates от reference canvas `1920x1080`. Minecraft GUI Scale влияет только на
перевод в `GuiGraphics`, поэтому final framebuffer bounds не меняются при GUI Scale `1`, `2`, `3`, `4` и `Auto`.

Проверка:

```text
/echo_hud bounds
```

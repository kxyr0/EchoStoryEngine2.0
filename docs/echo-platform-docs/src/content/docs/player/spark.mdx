# Искра

`PlayerSpark` хранит `current` и `maximum`. Инварианты: `0 <= current <= maximum`, `maximum > 0`, `maximum <= 1_000_000`.

<SparkMutationLab client:load />

`SpendSpark` не делает частичного списания. При нехватке значения профиль остаётся прежним и результат операции — `INSUFFICIENT_SPARK`.

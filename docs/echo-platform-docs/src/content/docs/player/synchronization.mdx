# Синхронизация профиля

Сервер отправляет immutable snapshot при login, reconnect, tracking start и после mutation. Клиентский mirror не является authority.

Stale packet игнорируется, если incoming revision старее локальной. При revision gap клиент должен запросить full snapshot вместо применения неполной delta.

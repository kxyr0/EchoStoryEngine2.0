# Persistence профиля

Domain API остаётся typed Java records. NBT/JSON/properties — только формат хранения.

Persistence сохраняет identity, имя, Spark, base appearance, template provenance, lifecycle metadata и revisions. При restart тот же UUID аккаунта восстанавливает тот же `EchoPlayerId`; duplicate profiles для одного игрока недопустимы.

# Основа Wardrobe

P1 не реализует одежду, шкаф, outfit inventory, cosmetics или armor replacement.

Будущий `echo-wardrobe` сможет читать `EchoPlayerId`, immutable base appearance, skin model и appearance revision через `player-forge-api`. Внутренний repository, SavedData и renderer implementation наружу не раскрываются.

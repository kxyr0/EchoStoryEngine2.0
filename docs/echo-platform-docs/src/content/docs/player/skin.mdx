# Скин игрока

`ACCOUNT` использует vanilla account skin. Мод не скачивает skin, не вызывает Mojang API и не хранит base64.

`RESOURCE` использует authored `PlayerSkinId`, например `jdh:player/default`, и модель `CLASSIC` или `SLIM`.

<SkinResolutionLab client:load />

Broken PNG не публикуется: client остаётся на previous known-good или падает обратно на account skin.

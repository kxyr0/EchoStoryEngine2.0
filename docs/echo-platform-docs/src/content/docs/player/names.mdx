# Имя игрока

`ACCOUNT` берёт resolved display name из текущего `GameProfile`. Смена имени аккаунта обновляет presentation name при следующем login, но `EchoPlayerId` остаётся прежним.

`CUSTOM` хранит plain `PlayerDisplayName`. Смена имени аккаунта не меняет custom name.

Validation: имя не пустое, не состоит только из пробелов, не содержит control characters и не превышает 48 Unicode code points. Formatting injection, MiniMessage и HTML не входят в P1.

# UI image texture authoring

Для пиксельного Minecraft UI текстура должна быть подготовлена под выбранный render mode.

## SIMPLE

Делать цельную картинку. Не рисовать рамку, если её нельзя растягивать.

## SLICED

Углы и уникальный декор должны быть внутри fixed corner regions. Повторяемые или растягиваемые части должны находиться
только в edge/center regions.

## TILED

Tile regions должны быть бесшовными:

- верхний и нижний края должны стыковаться по X;
- левый и правый края должны стыковаться по Y;
- центр должен стыковаться по двум осям.

Нельзя рисовать уникальную царапину внутри repeatable edge, если она не должна повторяться.

## FILLED

Foreground texture должна хорошо выглядеть при линейной обрезке. Не полагаться на сжатие: скрытая часть просто не
рисуется.

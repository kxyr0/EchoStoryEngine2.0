# 9-slice texture guide

Документ описывает текущую тестовую текстуру:

`dialogue-forge-1.20.1/src/main/resources/assets/echo_dialogue/textures/gui/panel/test_dialogue_panel.png`

В live Prism она также лежит здесь:

`story/content-pack/jdh/assets/jdh/textures/echo_dialogue/gui/panel/test_dialogue_panel.png`

Размер: `29x28 px`.

Координаты ниже включительные. Origin находится в левом верхнем углу.

## Borders

- `left = 6`
- `right = 5`
- `top = 6`
- `bottom = 8`

Из этого получается сетка:

- левая колонка: `x = 0..5`
- центральная колонка: `x = 6..23`
- правая колонка: `x = 24..28`
- верхняя строка: `y = 0..5`
- центральная строка: `y = 6..19`
- нижняя строка: `y = 20..27`

## 9 областей

| Область | Координаты |
| --- | --- |
| Левый верхний угол | `x=0..5`, `y=0..5` |
| Верхний край | `x=6..23`, `y=0..5` |
| Правый верхний угол | `x=24..28`, `y=0..5` |
| Левый край | `x=0..5`, `y=6..19` |
| Центр | `x=6..23`, `y=6..19` |
| Правый край | `x=24..28`, `y=6..19` |
| Левый нижний угол | `x=0..5`, `y=20..27` |
| Нижний край | `x=6..23`, `y=20..27` |
| Правый нижний угол | `x=24..28`, `y=20..27` |

## Что править художнику

Если нужно поменять углы, править эти зоны:

- `x=0..5`, `y=0..5`
- `x=24..28`, `y=0..5`
- `x=0..5`, `y=20..27`
- `x=24..28`, `y=20..27`

Если нужно поменять рамку, править эти зоны:

- верхний край: `x=6..23`, `y=0..5`
- левый край: `x=0..5`, `y=6..19`
- правый край: `x=24..28`, `y=6..19`
- нижний край: `x=6..23`, `y=20..27`

Если нужно поменять заливку центра, править центральную область:

- `x=6..23`, `y=6..19`

## Честная оценка текущей текстуры

Текстура подходит как первый тестовый asset: у неё есть прозрачные углы, рамка, светлый центр и нижняя тень.

Для очень высоких панелей она неидеальна: в левой части есть тёмные декоративные пиксели внутри вертикально
растягиваемой зоны. При сильном растяжении они будут вытягиваться, а не повторяться.

Для production-панели с большим диапазоном высот лучше сделать вертикальные edge-зоны более стабильными: одинаковая
рамка вдоль `y=6..19`, без уникального декора, который должен оставаться фиксированным. Если декор должен оставаться
неизменным, его нужно переносить в fixed top/bottom/corner зоны или делать отдельный tiled renderer.

## Почему не 4 px

Для этой картинки `4 px` не захватывает весь радиус скругления и нижнюю тень. При `4/4/4/4` часть углов и shadow
попадает в растягиваемые зоны. Значения `6/5/6/8` безопаснее для демонстрации и будущей panel texture.

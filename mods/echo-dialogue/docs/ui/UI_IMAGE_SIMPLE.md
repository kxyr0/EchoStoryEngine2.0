# UI image SIMPLE

`SIMPLE` берёт source region целиком и растягивает её на весь destination rectangle.

Семантика:

- slice borders игнорируются;
- tile settings игнорируются;
- fill settings игнорируются;
- source region может быть всей texture или частью atlas;
- рамка и углы будут искажаться, если destination отличается от source proportions.

`SIMPLE` подходит для цельных изображений: иконок, полноэкранных фонов, иллюстраций и декоративных картинок без
раздельных краёв.

Типичная ошибка: использовать `SIMPLE` для рамки. В этом случае углы и толщина рамки растягиваются вместе с центром.

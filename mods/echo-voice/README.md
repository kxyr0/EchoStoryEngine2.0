# Echo Voice

Изменения: [реестр](docs/changelogs/README.md).

Filename-based client-side foreground and positional ambient voice playback for Echo Dialogue on Forge 1.20.1.

Modules: `voice-contracts`, `voice-core`, `voice-forge-api-1.20.1`, `voice-forge-1.20.1`, and development-only `voice-testmod-1.20.1`.

Build: `gradlew.bat check build`

Build and deploy to Prism: `deploy_prism.bat`

# Echo Magic

Echo Magic 0.4.4 — общий server-authoritative движок заклинаний для Forge 1.20.1. Заклинания описываются в `.es`, проходят EchoScript parser, `SpellDefinitionBinder` и validator, после чего атомарно публикуются в каталог.

Управление жестами:

- `N` — выбрать и запомнить школу магии;
- `V` — начертить и применить технику активной школы;
- ЛКМ — рисовать отдельный штрих, пока `N` или `V` остаётся зажатой;
- отпускание `N`/`V` — закончить весь рисунок и отправить его на серверную проверку.

После основной техники можно поставить отдельную удерживаемую точку для задержки/печати, начертить `J`-образный крюк с точкой для связи с целью либо добавить расходящуюся развилку для разделения атаки на три направления.

В меню `Эхо магии → Обучить личный почерк` можно выбрать школу или технику и трижды нарисовать её обычной клавишей `N`/`V`. Сервер сохранит усреднённый персональный шаблон как дополнительный способ распознавания.

Клавиши переназначаются через `Настройки → Управление → Назначение клавиш → Эхо магия` или кнопкой `Настроить клавиши N / V` на экране `Эхо магии`. Там же можно отключить замедление времени.

Модули: `magic-contracts`, `magic-core`, `magic-forge-api-1.20.1`, `magic-forge-1.20.1`, `magic-script-adapter-1.20.1`, `magic-testmod-1.20.1`.

Сборка: `gradlew.bat clean check build`. Production JAR: `magic-forge-1.20.1/build/libs/echo-magic-0.6.0-all.jar`.

Движок не содержит зависимостей или специальных веток для отдельных школ магии. Удаление content-мода оставляет API, каталог, persistence и casting runtime работоспособными.

Story unlock integration: when Echo Core >=0.2.0 is installed, access requires its per-player saved flag. See ../echo-core/README.md for commands, Story action examples, and persistence. Without Echo Core, standalone behavior is preserved.

# Ошибки Magic

Основные коды: `MAGIC_PLAYER_CONTEXT_MISSING`, `MAGIC_SPELL_NOT_FOUND`, `MAGIC_SPELL_NOT_KNOWN`, `MAGIC_SPELL_NOT_SELECTED`, `MAGIC_SPELL_ON_COOLDOWN`, `MAGIC_CAST_DIRECTION_INVALID`, `MAGIC_PROJECTILE_DUPLICATE_HIT`, `MAGIC_DAMAGE_TYPE_NOT_FOUND`, `MAGIC_PARTICLE_BUDGET_EXCEEDED`, `MAGIC_DEFINITION_BIND_FAILED`.

Diagnostics содержат стабильный code, severity, сообщение, source и время. Runtime хранит bounded список.

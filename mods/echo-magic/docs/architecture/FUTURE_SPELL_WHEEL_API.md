# API будущего spell wheel

Wheel использует `SpellCatalogView`, `KnownSpellView`, `SelectedSpellView`, `SpellCooldownView`, `SpellSelectionService` и `SpellCastService`. Display name приходит из definition.

UI не импортирует конкретные magic schools. M1 не реализует radial menu, HUD icons, mana или mouse-wheel selection.

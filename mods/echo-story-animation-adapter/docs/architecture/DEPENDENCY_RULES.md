# Dependency Rules

Allowed dependencies:

- Echo Story public contracts.
- Echo Story public extension API and Forge extension bridge.
- Echo Animation public contracts.
- Echo Animation public Forge service API.
- Forge lifecycle events.

Forbidden dependencies:

- Story core, definition, persistence, or host implementation packages.
- Animation runtime, resource, networking, client renderer, or EchoScript implementation packages.
- Echo NPC and Echo Dialogue implementation packages.
- ServiceLoader, reflection, local files, background executors.

# Changelog

## 0.1.1

- Added `holdLastFrame=true` / `hold=true` forwarding for `Cutscene.Start` and `Cutscene.Play`.

## 0.1.0

- Added Forge adapter from Echo Dialogue external waits to Echo Cutscene playback.
- Supported command wait types: `echo_cutscene:start`, `echo_cutscene:play`, `echo_cutscene:wait`, `echo_cutscene:stop`.

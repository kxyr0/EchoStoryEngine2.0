# Echo Immortal Test Target

Отдельный Forge 1.20.1 мод с неубиваемой тестовой целью в виде обычного зомби.

- Получает удары, анимацию урона и knockback, но здоровье всегда остаётся полным.
- Игнорирует `/kill`, любой damage и уничтожающее удаление сущности.
- Не удаляется на мирной сложности и редко появляется как peaceful-compatible creature.
- Не загорается от солнечного света.
- Не ходит и не атакует сама: AI-goals пустые, но gravity, collision, падение и knockback работают.
- Яйцо призыва находится во вкладке `Яйца призыва`.
- `/echo_test_target spawn [1..64]` создаёт цели перед исполнителем.
- `/echo_test_target clear` — намеренный административный способ удалить все цели во всех измерениях.

Сборка: `gradlew.bat clean build`. Production JAR: `build/libs/echo-test-target-0.1.2.jar`.

# История изменений

## 0.1.2

- Отключены только AI-goals, а не весь `NoAI` runtime: цель снова падает, сталкивается и получает knockback.
- Старые уже созданные цели автоматически мигрируют из `NoAI` при следующем tick.

## 0.1.1

- Тестовая цель больше не загорается от солнечного света.

## 0.1.0

- Добавлена зомбиобразная неубиваемая тестовая цель.
- Добавлены мирный естественный spawn, яйцо призыва и команды `spawn/clear`.

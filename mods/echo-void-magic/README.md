# Echo Void Magic

Echo Void Magic 0.2.2 — runtime школы Пустоты для Echo Magic. Production-мод содержит data-driven Void damage type, generic billboard particle registration, исходный `void_circle.png`, runtime Void Step и публичный слой эффектов `jdh:void_sword` для боевых адаптеров. `.es` определения Void Daggers и Void Step находятся в JDH story content pack.

Зависимость: обязательный public API мода `echo_magic` версии 0.4.4+. Отдельного casting engine и Java-класса Void Daggers нет.

Сборка: `gradlew.bat clean check build`. Production JAR: `void-magic-forge-1.20.1/build/libs/echo-void-magic-0.2.2.jar`.

# Команды Void Magic

`/echo_void_magic setup <player>` получает public `MagicService`, выдаёт `echo_void_magic:void_daggers`, выбирает его, очищает cooldown для теста и показывает локализованную подсказку про назначенную клавишу применения.

Default — `V`. Переназначение: `Настройки → Управление → Назначение клавиш → Магия Echo → Применить выбранное заклинание`.

`/echo_void_magic_test acceptance` печатает последовательность ручной проверки. Production state не обходится.

# Void damage

`data/echo_void_magic/damage_type/void_magic.json` регистрирует `echo_void_magic:void_magic`. Тип не обходит armor, shield, creative или invulnerability, не является fire/explosion/arrow.

`data/forge/tags/damage_type/is_magic.json` добавляет совместимый magic tag. Damage применяет стандартный server `hurt` pipeline.

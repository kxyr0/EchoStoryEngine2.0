# Проверка Void Magic

1. Запустить dev client с Echo Magic, Echo Magic Testmod, Echo Void Magic и Void Testmod.
2. Выполнить `/echo_magic_test arena`.
3. Выполнить `/echo_void_magic setup <player>`.
4. Использовать назначенную клавишу `Применить выбранное заклинание` и проверить три emissions, cooldown, ally/caster exclusion, wall stop и 2.0 damage на projectile. Default-клавиша — `V`, но тест не должен зависеть от конкретного bind.
5. Повторить first/third person, 30/60/144 FPS, GUI Scale 1–4, день/ночь и светлый/тёмный фон.

Автоматические tests не заменяют эту визуальную проверку.

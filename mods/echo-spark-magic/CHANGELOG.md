# Changelog

## 0.1.0

- Добавлена movement-only школа `echo_spark_magic:spark`.
- Добавлена particle `echo_spark_magic:spark_circle` с ярко-жёлтым центром и тёмно-жёлтыми краями.
- Добавлен server-authoritative trail, создаваемый только при изменении позиции игрока.
- Добавлено persistent включение/выключение с сохранением после respawn.
- Добавлены команды `setup`, `enable`, `disable` и `status`.

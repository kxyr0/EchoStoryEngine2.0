# Echo Damage Numbers

Отдельный Forge 1.20.1 мод с world-space цифрами фактического урона.

- Popup получает только игрок, который нанёс урон.
- Цифры появляются только над врагами: hostile `Enemy`, агрессивным к игроку мобом или вражеским игроком.
- Союзники, члены команды, собственные приручённые существа и мирные NPC отфильтрованы.
- Показывается финальный damage после брони, эффектов и absorption.
- Анимация: быстрый scale-in с небольшим overshoot, подъём по синусоиде, затем scale-out и fade.
- Большой урон меняет цвет с жёлтого на оранжевый и красный.

Сборка: `gradlew.bat clean build`. Production JAR: `build/libs/echo-damage-numbers-0.1.0.jar`.

КАК НАЛОЖИТЬ:
1. Сделай git commit/backup текущего echo-animation.
2. Скопируй СОДЕРЖИМОЕ этого архива поверх:
   D:\JDHSeason\mods\echo-animation\
3. Из корня echo-animation выполни:
       python apply_rejoin_nbt_codec_patch.py
4. Затем:
       python verify_merge.py
5. Потом собирай проект обычным Gradle workflow.

apply_rejoin_nbt_codec_patch.py не переписывает весь NBT codec. Он вставляет одну
строку в существующий AnimationRuntimeNbtCodec.java и падает с ошибкой, если не
находит ожидаемый метод. Это сделано специально, чтобы не затереть твои изменения.

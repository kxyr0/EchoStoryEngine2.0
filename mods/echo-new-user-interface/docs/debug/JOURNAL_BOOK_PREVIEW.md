# Journal Book Preview

Preview является debug-only режимом первого milestone.

Состояния:

- default: hidden;
- `show`: visible;
- `hide`: hidden;
- `toggle`: меняет visible/hidden;
- `status`: печатает текущий viewport, physical rectangle, GUI rectangle, scale, center error и diagnostics.

На страницах нет текста, кнопок, mouse input, прокрутки, page turning или opening animation.

Во время preview остальные HUD overlays подавляются.

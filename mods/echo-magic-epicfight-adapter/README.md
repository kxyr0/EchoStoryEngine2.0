# Echo Magic: Epic Fight Adapter

Универсальный адаптер временного оружия Echo Magic для Epic Fight 20.14.x.

Адаптер не знает ID школ и предметов. Он читает `SummonedWeaponData` из NBT предмета,
синхронизирует particle-клинок с текущей `AttackAnimation` и поддерживает движения `thrust`
и `slash`. Поэтому новое призванное оружие не требует нового Java-адаптера.

Положение оружия берётся из фактического main-hand tool joint текущей позы Epic Fight. Клинок
движется вместе с кистью в idle, при ходьбе и во время атаки; положение камеры для якоря не
используется. Собственного PNG у оружия и адаптера нет — короткоживущий glow переиспользует
ванильную particle-текстуру.

Для нового оружия нужны только:

1. настоящий зарегистрированный `Item`;
2. вызов `SummonedWeaponData.configure(...)` при призыве;
3. Epic Fight capability JSON в `data/<modid>/capabilities/weapons/<item>.json`;
4. невидимая модель `minecraft:builtin/entity`, если клинок должен целиком состоять из частиц.

Ограничения автоматически проверяются сборкой: максимум 200 логических строк в Java-файле
и максимум 7 Java-файлов в одной папке.

# Wardrobe animation integration

Echo Animation reads resolved appearance through Echo Content Player's neutral boundary.

Forbidden links:

- Echo Animation imports Echo Wardrobe: 0
- Echo Wardrobe imports Echo Animation: 0

Animation consumers may use `ResolvedPlayerAppearance.worldSkin`, `faceSkin`, model descriptors, and `appearanceRevision`. They must not depend on `wardrobe-core` or Forge runtime classes.

# Wardrobe slots

W2 slots are intentionally fixed:

| Wardrobe slot | Vanilla equipment slot |
| --- | --- |
| `FACE` | `HEAD` |
| `TOP` | `CHEST` |
| `BOTTOM` | `LEGS` |
| `FEET` | `FEET` |

`FACE` represents glasses or another head-mounted selection. It participates in `OutfitKey`, but the skin still comes from the exact outfit variant, not from a runtime face layer.

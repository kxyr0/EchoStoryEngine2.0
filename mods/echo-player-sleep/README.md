# Echo Player Sleep

Echo Player Sleep превращает подтверждённый ванильный сон игрока в точку входа в авторский сценарий сна.

Главное правило: мод не подделывает сон. Сценарий запускается только после успешного vanilla bed interaction и подтверждённого sleeping state. Без `Sleep.Arm(...)` ванильный сон не меняется.

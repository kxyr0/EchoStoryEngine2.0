# Echo Audio 0.2.0

Универсальные EchoScript SFX для Forge 1.20.1. Использует существующие декодеры Echo Voice,
сохраняя отдельные SFX playback, владение и канал Minecraft BLOCKS.

Единственное руководство: [AUDIO_DSL.md](../../docs/runtime/AUDIO_DSL.md).
Проверка: `./gradlew.bat check build`.
Изменения: [реестр](docs/changelogs/README.md).

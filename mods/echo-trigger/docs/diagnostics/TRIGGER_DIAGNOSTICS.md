# Trigger Diagnostics

T2 and T3 diagnostic codes are stable and queryable:

- `TRIGGER_ITEM_ID_NOT_FOUND`, `TRIGGER_ITEM_TAG_NOT_FOUND`, `TRIGGER_ITEM_COUNT_INVALID`
- `TRIGGER_ITEM_EVENT_BASELINE_MISSING`
- `TRIGGER_EFFECT_ID_NOT_FOUND`, `TRIGGER_EFFECT_AMPLIFIER_INVALID`
- `TRIGGER_ADVANCEMENT_NOT_FOUND`, `TRIGGER_EXPERIENCE_LEVEL_INVALID`
- `TRIGGER_BLOCK_ID_NOT_FOUND`, `TRIGGER_BLOCK_TAG_NOT_FOUND`, `TRIGGER_BLOCK_EVENT_DUPLICATE_COALESCED`
- `TRIGGER_EQUIPMENT_SLOT_INVALID`, `TRIGGER_GAME_MODE_INVALID`
- `TRIGGER_DAMAGE_SOURCE_INVALID`, `TRIGGER_HEALTH_VALUE_INVALID`, `TRIGGER_FOOD_VALUE_INVALID`
- `TRIGGER_TIME_VALUE_INVALID`, `TRIGGER_WEATHER_VALUE_INVALID`
- `TRIGGER_PROVIDER_SCHEMA_UNSUPPORTED`, `TRIGGER_PROVIDER_RECOVERY_FAILED`
- `TRIGGER_PREDICATE_DEPENDENCY_MISSING`, `TRIGGER_EVENT_RESULT_INVALID`
- `TRIGGER_CALLBACK_NOT_FOUND`, `TRIGGER_CALLBACK_DUPLICATE`, `TRIGGER_CALLBACK_SIGNATURE_INVALID`
- `TRIGGER_CALLBACK_SIGNATURE_AMBIGUOUS`, `TRIGGER_CALLBACK_EXECUTION_FAILED`
- `TRIGGER_CALLBACK_RECOVERY_FAILED`, `TRIGGER_HANDLER_REVISION_MISSING`
- `TRIGGER_MULTIPLE_PRIMARY_AREAS`, `TRIGGER_AREA_NOT_BOUND`, `TRIGGER_AREA_SHAPE_INVALID`
- `TRIGGER_AREA_MIN_MAX_INVALID`, `TRIGGER_AREA_RADIUS_INVALID`, `TRIGGER_POLYGON_INVALID`
- `TRIGGER_POLYGON_SELF_INTERSECTION`, `TRIGGER_AREA_DIMENSION_MISSING`
- `TRIGGER_MEMBERSHIP_POLICY_INVALID`, `TRIGGER_FIRE_POLICY_CONFLICT`, `TRIGGER_FIRE_LIMIT_REACHED`
- `TRIGGER_FIRE_TOKEN_RECOVERY_FAILED`, `TRIGGER_COOLDOWN_ACTIVE`
- `TRIGGER_STAY_INTERVAL_INVALID`, `TRIGGER_STAY_POLICY_INVALID`, `TRIGGER_STAY_SKIPPED_RUNNING`
- `TRIGGER_EVENT_QUEUE_OVERFLOW`, `TRIGGER_EVENT_DUPLICATE`, `TRIGGER_EVENT_RECOVERY_FAILED`
- `TRIGGER_DIALOGUE_EXTENSION_UNAVAILABLE`, `TRIGGER_STORY_EXTENSION_UNAVAILABLE`
- `TRIGGER_PLAYER_EXTENSION_UNAVAILABLE`, `TRIGGER_DEBUG_VIEW_UNAVAILABLE`
- `TRIGGER_AREA_SOURCE_UNAVAILABLE`

Diagnostics are rate-limited by provider and tied to source plus `TriggerInstanceId` when runtime context exists.

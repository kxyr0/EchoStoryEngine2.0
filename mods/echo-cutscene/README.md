# Echo Cutscene

Главный справочник по катсценам и интеграции с Dialogue: [docs/cutscene.md](docs/cutscene.md).

Echo Cutscene отвечает только за камеру катсцены и блокировку gameplay input. Настоящий `ServerPlayer` остаётся в мире, `GameMode` не меняется, Dialogue и appearance-системы остаются владельцами своих состояний.

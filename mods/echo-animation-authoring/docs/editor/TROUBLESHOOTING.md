# Troubleshooting

`Workspace не настроен; запись запрещена.`

Configure the content-pack root before saving or exporting.

`Путь выходит за пределы workspace`

Choose an output path under the configured content-pack root.

`Поле tilt не мигрировано автоматически`

Review the legacy animation manually and decide whether the old tilt maps to `rotationZ`.

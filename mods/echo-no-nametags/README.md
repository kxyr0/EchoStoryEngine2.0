# Echo No Name Tags

Отдельный клиентский микро-мод Forge 1.20.1. Скрывает подписи над сущностями,
включая Echo NPC с обычной моделью и с моделью, заменённой render extension.
Не меняет имена персонажей в диалогах, каталог NPC и сохранения.

Версия 0.1.1 отменяет Forge RenderNameTagEvent с приоритетом LOWEST и блокирует
сам EntityRenderer.renderNameTag через client-only Mixin. Второй путь нужен,
поскольку заменённая модель Echo NPC вызывает отрисовку подписи напрямую,
без RenderNameTagEvent. Mixin требует успешного внедрения, чтобы несовпадение
версии Minecraft не превращалось в незаметную утечку имён.

Сборка из этого каталога с wrapper соседнего проекта:

```powershell
..\echo-npc\gradlew.bat -p . build --console=plain
```

Установка: заменить прежний echo-no-nametags JAR в mods и перезапустить игру.
Ручная проверка: обычный Echo NPC, NPC с заменённой моделью, наведение прицела,
приседание, разные расстояния и перезагрузка ресурсов. Во всех случаях подпись
должна отсутствовать, а имя в диалоге должно оставаться видимым.

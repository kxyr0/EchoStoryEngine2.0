# Code Style

- Java source target is release 17.
- Public API types require clear Javadoc.
- One public top-level type per file.
- Line length is 120.
- Wildcard imports are forbidden.
- Static mutable fields are forbidden.
- Avoid generic names such as Manager, Helper, Utils, Common, Processor, Handler, and Impl.
- Split production code by reason to change, not by line-count games.

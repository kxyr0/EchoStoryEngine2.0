# Development Workflow

For non-trivial work:

1. Read `AGENTS.md`.
2. Read `docs/architecture/PROJECT_MAP.md`.
3. Read `PROGRESS.md`.
4. Inspect git status when Git is initialized.
5. Plan the cohesive change.
6. Confirm the work is within syntax-only scope.
7. Implement and test.
8. Run relevant checks and `.\gradlew.bat check`.
9. Review the diff.
10. Update docs and progress.
11. Do not commit without explicit user request.

# Keyframes

Viewport LMB drag creates or replaces one keyframe mutation in the active authoring draft after the gizmo picker resolves
a handle. The mutation uses the current frame, the selected bone when present and `body` as the fallback bone.

Tool hotkeys choose the transform kind before dragging:

- T enables translate axes and translate planes;
- R enables rotate X/Y/Z rings;
- S enables axis and uniform scale handles.

Timeline keyframe create/move/delete controls are still pending.

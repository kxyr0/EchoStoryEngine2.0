# Shortcuts

- Esc closes the editor.
- Ctrl+S saves the active authoring draft.
- Ctrl+Shift+S autosaves the active authoring draft sidecar.
- Ctrl+Z undoes the last authoring draft edit.
- Ctrl+Y redoes the next authoring draft edit.
- Ctrl+R recovers the active clip from autosave.
- Ctrl+P applies the authoring preview hook.
- Ctrl+X clears the authoring preview hook.
- T selects translate.
- R selects rotate.
- S selects scale.
- B selects BODY mode.
- F selects FACE mode.
- RMB drag rotates the editor camera.
- WASD/QE moves the editor camera.
- Shift and Ctrl change camera speed while held.

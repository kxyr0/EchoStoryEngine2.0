# Animator Editor Diagnostics

Implemented diagnostic codes include:

- `ANIMATOR_EDITOR_SESSION_ALREADY_ACTIVE`
- `ANIMATOR_EDITOR_SESSION_NOT_ACTIVE`
- `ANIMATOR_EDITOR_CAMERA_ATTACH_FAILED`
- `ANIMATOR_EDITOR_OPENED`
- `ANIMATOR_EDITOR_CLOSED`

Public API probes report Echo Animation and Echo NPC bridge status in `/echo_animator status`.
